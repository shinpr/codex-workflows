# Scope Confirmation

Use only information that can change the user's requirement decision or the workflow route. Only explicit user selections enter **Confirmed scope**. Keep repository observations and agent interpretations labeled under **Decision evidence**. Keep open product, UX, and operational choices under **User decisions** until the user answers them.

## Confirmed scope

State the requirements and exclusions already selected by the user.

## Decision evidence

- **Fact**: A material observed fact.
  - **Implication**: What that fact can change about scope, outcome, or cost.

## User decisions

- For each unresolved user-owned decision, write the question followed by the scope, outcome, or cost effects of its materially different answers.

## Workflow

- Rough cost and Structural Scale
- Selected document and workflow route
